# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository
(Security → Report a vulnerability). Do not open a public issue, and do
not report a vulnerability only in a pull request.

## Scope

The OpenTofu, Talos and Flux configuration in this repository. A finding
that needs the running cluster to exploit still counts: these manifests
describe it. A vulnerability in an upstream tool belongs upstream.

## Supported versions

The `main` branch only; the cluster runs it and there are no releases.
